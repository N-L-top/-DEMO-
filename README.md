# 电商销售数据可视化分析（E-commerce Sales Data Analysis）

一个使用 Python + Pandas + NumPy + Matplotlib 对电商订单数据进行清洗、聚合与可视化的数据分析项目。目标是从原始订单数据中提取有业务价值的洞察，帮助理解销售结构、趋势与客户行为。

## 项目概览

本项目完成一个完整的数据分析流程：**数据加载 → 数据清洗 → 探索性分析（EDA）→ 可视化 → 结论输出**。分析对象为一份约 3 万条的电商销售订单数据集。

## 技术栈

- 语言：Python 3.8+
- 数据分析：Pandas、NumPy
- 可视化：Matplotlib、Seaborn
- 运行环境：Jupyter Notebook

## 数据集

文件：`ecommerce_sales.csv`

字段说明：

| 字段 | 含义 |
| --- | --- |
| 订单号 | 唯一订单编号 |
| 订单日期 | 下单日期（2024年全年） |
| 产品类别 | 8 大类商品 |
| 产品名称 | 具体商品 |
| 销售区域 | 6 大区域 |
| 城市 | 下单城市 |
| 销售渠道 | 线上商城 / APP / 小程序 / 线下门店 |
| 客户类型 | 个人用户 / 企业采购 / 会员用户 |
| 数量 | 购买件数 |
| 单价 | 商品单价 |
| 折扣率 | 折扣比例（0 表示无折扣） |
| 销售额 | 实际成交金额 = 单价 × 数量 × (1 - 折扣率) |

## 分析目标

1. 整体销售规模：总销售额、订单量、客单价
2. 按月销售趋势，识别旺季与促销期
3. 各产品类别的销售额占比与排名
4. 各销售区域的销售分布
5. 各销售渠道的贡献对比
6. 折扣率对销售额的影响（折扣是否带来更多销量）

## 结果小结

- 总销售额：116907751 元
- 总订单量：30000 笔
- 销售额最高的产品类别：电子产品
- 销售额最高的区域：华东
- 销售额最高的渠道：线上商城
- 主要洞察：在有折扣的情况下平均件数更高
