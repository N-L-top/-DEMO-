# 电商销售数据可视化分析（E-commerce Sales Data Analysis）

一个使用 Python（Pandas、NumPy、Matplotlib、Seaborn）对电商订单数据进行清洗、探索性分析、客户分层、盈利分析与销量预测的端到端数据项目。目标是从原始订单数据中提取有业务价值的洞察，并把「数据 → 洞察 → 决策」的完整链路走通。

## 项目概览

本项目覆盖数据分析的完整流程：**数据加载 → 数据清洗 → 探索性分析（EDA）→ RFM 客户分层 → 盈利/折扣优化 → 销量预测 → 结论输出**，并全部以可复现的 Jupyter Notebook 形式开源。

分析的三个进阶主题：

1. **RFM 客户分层** —— 识别高价值核心客户，支撑用户运营策略
2. **盈利 / 折扣优化** —— 找出利润最大的折扣区间
3. **月度销量预测** —— 用趋势模型预测后续销路

## 技术栈

- 语言：Python 3.8+
- 数据分析：Pandas、NumPy
- 可视化：Matplotlib、Seaborn
- 运行环境：Jupyter Notebook
- 依赖：`pandas numpy matplotlib seaborn jupyter`（**无需额外安装 scikit-learn**，销量预测用 numpy 实现）

## 数据集

文件：`ecommerce_sales.csv`（约 3 万条订单）

| 字段 | 含义 |
| --- | --- |
| 订单号 | 唯一订单编号 |
| 客户ID | 客户唯一标识（用于 RFM 分层） |
| 订单日期 | 下单日期（2024 年 1 月 ~ 12 月） |
| 产品类别 | 8 大类商品 |
| 产品名称 | 具体商品 |
| 销售区域 | 7 大区域 |
| 城市 | 下单城市 |
| 销售渠道 | 线上商城 / APP / 小程序 / 线下门店 |
| 客户类型 | 个人用户 / 企业采购 / 会员用户 |
| 数量 | 购买件数 |
| 单价 | 商品单价 |
| 折扣率 | 折扣比例（0 表示无折扣） |
| 单位成本 | 单件商品成本 |
| 销售额 | 实际成交金额 = 单价 × 数量 × (1 - 折扣率) |
| 成本 | 总成本 = 单位成本 × 数量 |
| 毛利 | 销售额 - 成本 |

**数据规模与质量**：30,000 条订单，2,197 位客户，16 个字段；无缺失值、无重复行。

**整体经营指标**：
- 总销售额：约 1.17 亿元（117,273,687 元）
- 总毛利：约 2,699 万元（26,990,288 元）
- 整体毛利率：23.0%

## 分析结果

### 1. RFM 客户分层

按 R（最近消费距今天数，越小越活跃）、F（消费频次，越大越忠诚）、M（累计消费金额，越大越有价值）三个维度打分，将 2,197 位客户划分为 5 类：

| 客户分层 | 客户数 | 客户占比 | 销售额贡献 |
| --- | ---: | ---: | ---: |
| 重要价值客户 | 579 | 26.4% | **42.7%** |
| 重要保持客户 | 292 | 13.3% | 20.2% |
| 流失风险客户 | 694 | 31.6% | 16.9% |
| 潜力客户 | 430 | 19.6% | 13.6% |
| 一般客户 | 202 | 9.2% | 6.6% |

**业务洞察**：占比 26.4% 的「重要价值客户」贡献了 42.7% 的销售额，符合二八法则，应作为重点维护对象；16.9% 的销售来自 31.6% 占比的「流失风险客户」，这批客户复购下降，是需要挽回的高优先群体。

### 2. 盈利 / 折扣优化

销售额高不等于赚钱。分析各折扣档位下的平均购买件数与毛利率：

| 折扣率 | 平均购买件数 | 单均销售额 | 毛利率 |
| ---: | ---: | ---: | ---: |
| 0% | 3.35 | 3,206 元 | **33.1%** |
| 5% | 3.97 | 3,608 元 | 29.4% |
| 10% | 4.70 | 3,817 元 | 25.9% |
| 15% | 5.38 | 4,516 元 | 21.2% |
| 20% | 6.01 | 4,794 元 | 16.0% |
| 30% | 7.40 | 4,892 元 | **4.7%** |

**业务洞察**：折扣越高销量越大，但毛利率快速下降（从 33.1% 跌至 4.7%）。折扣能拉动销量，但当折扣达到 20%~30% 时，毛利率被显著侵蚀，存在「薄利」、利润反而走低的区间。**最优折扣区间应控制在 0%~10%** 之间，此时毛利率仍保持在 26% 以上，同时销量也有提升。

### 3. 月度销量预测

用 numpy 一元线性回归拟合月度销量趋势，前 9 个月训练、后 3 个月测试：

- 线性趋势：销量 ≈ -189.9 × t + 12,771（t 为时间序号）
- 测试集评估：MAE ≈ 5,695，RMSE ≈ 7,725，R² ≈ -0.23
- 未来 3 个月预测销量：约 10,492 / 10,303 / 10,113 件

**业务洞察与模型局限**：模型 R² 为负，说明**线性趋势并不能很好拟合销量**。原因在数据本身有较强的季节性波动（5 月、6 月、10 月、11 月为销售高峰），且 12 月样本量异常偏少（仅 556 件，为数据生成的边界效应），单靠线性趋势无法捕捉周期性。**改进方向**是引入季节性因子（月周期性）、改用非线性的时间序列模型（如 Prophet、ARIMA），或用更完整的月度数据重新建模。

## 项目亮点

- **完整的分析链路**：从清洗 → EDA → 分层 → 商业决策 → 预测，不是单一维度的「看数据」
- **可量化的业务结论**：RFM 识别核心客户、折扣区间利润最大化、销量预测，都能落到具体数字和决策建议
- **工程规范**：无缺失值/重复项处理 + IQR 异常值检测 + 中文字体自动适配
- **无需额外依赖**：全流程只用 pandas / numpy / matplotlib / seaborn，销量预测用 numpy 手写，降低跑通成本
